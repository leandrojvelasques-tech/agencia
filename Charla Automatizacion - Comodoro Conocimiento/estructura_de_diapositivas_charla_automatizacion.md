## 3. ¿Qué es automatizar?

- Diseñar un proceso para que una tarea se ejecute sola o con mínima intervención humana



BENEFICIOS:

- Ahorrar tiempo
- Reducir errores y estrés
- Mejorar escala y trazabilidad

## 4. Análisis previo antes de automatizar

#### Diapo 1: La automatización ¿resuelve el problema del cliente?

- ¿por qué el cliente quiere automatizar ese proceso?
- ¿está claro que automatizar esa parte va a producir una mejora real y no empeorar la situación?
- ¿o se está intentando automatizar algo secundario, sin atacar la dificultad principal?

**Diapo 2: Conocer en profundidad el proceso que se quiere automatizar**

- No se puede automatizar correctamente algo que no se entiende.
- qué está ocurriendo hoy, quiénes intervienen, qué responsabilidades tiene cada actor , cómo circula la información, cómo se mueve la documentación

Diapo 3: **Un stack de herramientas digitales adecuado mejora las posibilidades de que la automatización funcione**

## 6. ¿Cuándo conviene automatizar?&#x20;

Diapositiva 1: 

- Cuando hay reglas claras
- Cuando el error humano cuesta caro y/o es frecuente
- Cuando el volumen crece
- Cuando el beneficio supera el costo de implementación

Diapositiva 2: 

- Recepción y ordenamiento automático de documentación
- Envío automático de correos o mensajes ante determinados eventos
- Carga o actualización automática de información entre sistemas
- Clasificación o categorización automática de información
- Control periódico de novedades o cambios
- Generación de reportes o resúmenes recurrentes
- Procesamiento inicial de formularios, leads o inscripciones
- Derivación interna de tareas o pedidos

## 8. Ruta de trabajo para construir una automatización

**Diapositiva 1: Método tradicional-artesanal (prehistórico)**

1. Dar de alta n8n
2. Crear un asistente de apoyo (Ej: con ChatGPT)
3. Cargar credenciales en n8n
4. Promptear el workflow con el asistente
5. Construir el flujo nodo por nodo
6. Probar y corregir
7. Publicar el flujo y monitorear

**Diapositiva 2: Método moderno a través de un LLM - MCP**

1. Dar de alta n8n
2. Dar de alta LLM Ej: Claude/Antigravity
3. Configurar proyecto en LLM
4. Conectar via MCP LLM y n8n
5. Cargar "skill" de n8n en LLM
6. Promptear  el flujo en LLM
7. Chequear el flujo generado en n8n
8. Ajustar el flujo: cargar credenciales/renombrar nodos
9. Publicar workflow

**Diapositiva 3: Método nuevo -> Pedirle a un agente de IA (Open Claw)**

1. Dar de alta n8n
2. Dar de alta un LLM 
3. Dar de alta Open Claw en un VPS  
4. Solicitarle a Open Claw que se conecte al LLM para desarrollar el workflow.
5. Dormir una siesta
6. Chequear que esté funcionando.
